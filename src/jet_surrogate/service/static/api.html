API

Everything the site does is available as a JSON API, so you can submit files and collect results from a script.

Interactive OpenAPI docs

Quick start

Submit a file to an analysis and get a job id back:

curl -F analysis=<id> -F file=@events.hepmc -F "label=m = 8 GeV" -F max_events=20000 \
     https://<host>/api/jobs
# {"id": "abc123def456", "status": "queued"}

Poll the job until status is done or failed. Jobs are queued and run one after another:

curl https://<host>/api/jobs/<id>
# {"id": "abc123def456", "status": "done", "result": {"sr_efficiency": 0.4123, ...}}

Then fetch the per-event probabilities and the log:

curl -O -J https://<host>/api/jobs/<id>/result.h5   # per-event probabilities
curl https://<host>/api/jobs/<id>/log                # job log

Analysis ids come from the library:

curl https://<host>/api/analyses
curl https://<host>/api/analyses/<id>

Endpoints

All responses are JSON unless noted. Errors return a 4xx status with {"detail": "..."}.

GET/api/info

Service name, tagline, version, public URL, repository URL, upload limit in MB and the number of analyses.

GET/api/analyses

The library: a list of analysis summaries with id, title, short, experiment, status, version, updated, tags, repo_url, default_max_events and max_events.

GET/api/analyses/{id}

The full record: the summary fields plus description_html, signal_region, inputs, references, validation, figures, model and contact.

GET/api/analyses/{id}/figures/{file}

A validation figure (PNG).

POST/api/jobs

Submit a job. Multipart form fields: analysis (id), file (HepMC2 or HepMC3 ASCII, optionally gzipped), optional label and max_events. Returns {"id", "status"}.

GET/api/jobs?limit=50

Recent jobs, newest first.

GET/api/jobs/{id}

One job: id, analysis, status (queued, running, done or failed), created, started and finished as Unix seconds, label, source, max_events, progress, error and, when done, result with n_events, n_truth_jets, sr_efficiency, sr_efficiency_err, sr_efficiency_threshold05, mean_jet_probability, model, analysis, version and a histogram of the per-event probabilities (edges, counts).

GET/api/jobs/{id}/result.h5

The per-event probabilities as an HDF5 file (download).

GET/api/jobs/{id}/log

The job log as text.

Notes

  • The upload limit is reported by /api/info (max_upload_mb). Gzip large files.
  • max_events is capped at the max_events of the analysis.
  • Poll no more often than every few seconds. Jobs typically take a few minutes.
  • The web pages use exactly this API, so anything you see on the site you can script.
