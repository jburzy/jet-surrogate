# Static front end

This directory is the whole web front end of the surrogate reinterpretation service: plain HTML pages (`index.html`, `analyses.html`, `analysis.html`, `submit.html`, `jobs.html`, `contribute.html`, `api.html`), one stylesheet (`css/site.css`), one script (`js/app.js`), a favicon and sample API payloads in `fixtures/`. There is no build step. The pages use the IBM Carbon Design System loaded from the IBM CDN (Plex fonts and the Carbon token stylesheet), with all colors taken from `--cds-*` tokens so the light and dark themes both work. FastAPI serves this directory at `/` and the JSON API under `/api/`. Every page is driven by the API (`GET /api/info`, `GET /api/analyses`, `GET /api/analyses/{id}`, `GET /api/jobs`, `GET /api/jobs/{id}`, `POST /api/jobs`), so adding an analysis to the library needs no front-end change.

To preview without the backend, run `python3 -m http.server 8931 --directory src/jet_surrogate/service/static` from the repository root and open `http://localhost:8931/`. When `/api/info` is unreachable the script falls back to the payloads in `fixtures/` (set `window.JS_FIXTURES = true` in the config block at the top of `js/app.js` to force this), so every page renders with the example analysis and a finished example job, and the submit page simulates an upload. To preview against a running API instead, start the service (for example `uvicorn jet_surrogate.service.app:create_app --factory`) and open its root URL, or point a reverse proxy at it so that `/api/` and the static files share one origin. Bump the `?v=N` query on `css/site.css` in every page after a stylesheet change so browsers do not keep a stale copy.
